ShotMap for Windows

1. Extract this ZIP completely to a folder you can write to.
2. Get an x64 Windows build of FFmpeg with ffmpeg.exe and ffprobe.exe.
   For WebP export, choose a build with the libwebp encoder.
   https://ffmpeg.org/download.html#build-windows
3. Place the FFmpeg bin folder under ffmpeg in the ShotMap folder
   (ShotMap.exe and ffmpeg\bin\ffmpeg.exe share the same package root),
   or add the FFmpeg bin folder to PATH.
4. Open ShotMap.exe. Add videos using the plus button or drag and drop.

This preview was tested on Windows 11 x64. The .NET 10 Desktop Runtime
is included. ShotMap.exe is Authenticode unsigned. All media processing
runs locally. See the LICENSES folder for license information.

视频一键拼图（ShotMap）Windows 预览版

1. 将整个 ZIP 解压到可写的目录。
2. 从上面的 FFmpeg 下载页选择含 ffmpeg.exe 和 ffprobe.exe 的
   Windows x64 构建。WebP 导出需要构建包含 libwebp 编码器。
3. 将 FFmpeg 的 bin 文件夹放入 ShotMap 目录下的 ffmpeg 文件夹，
   或将 bin 加入 PATH。
4. 打开 ShotMap.exe。点击队列的加号，或直接拖入视频。

已在 Windows 11 x64 上测试。包内带 .NET 10 Desktop Runtime。
ShotMap.exe 未经 Authenticode 签名。视频和图片均在本机处理。
