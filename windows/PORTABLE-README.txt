ShotMap for Windows

1. Extract this ZIP completely to a folder you can write to.
2. Double-click ShotMap.exe. Add videos using the plus button or drag and drop.

This preview was tested on Windows 11 x64. The .NET 10 Desktop Runtime
and the FFmpeg and ffprobe command-line tools are included. ShotMap.exe
is Authenticode unsigned. All media processing runs locally.

The bundled FFmpeg libraries are licensed under LGPL 2.1 or later.
