找回记得的那个片段

不用挨个播放，先看画面总览。

  1. 添加视频

    拖入一部视频，也可以一次加入多部。

  2. 查看并微调

    ShotMap 会先挑选画面，不合适的帧可以手动替换。

  3. 导出分镜图

    保存为 PNG 或 JPG，需要时也可显示时间码。

画面由你决定

想找别的瞬间？自己选一帧。

智能选帧先给你一组候选。打开手动选择画面，用时间轴、逐帧按钮和时间码找到想要的画面，再替换即可。

  • 在视频时间轴上查看候选画面
  • 每次前后移动 1 帧或 5 帧
  • 已选画面按视频时间顺序排列

按你的需要整理画面

常用设置简单明了。

分镜网格

从 3 × 3 到 8 × 8，按需要选择画面密度。

水印标注文件名

可以选择显示文件标题、时间码，方便之后快速查找。

匹配你的素材

按视频比例排版，还能选择分镜图的底色。

批量处理队列

一次加入多部视频，查看处理进度，并集中浏览已完成的分镜图。

视频只留在你的设备上

视频始终留在你的 Mac 上。

画面提取和图片导出都在本机完成，视频不会上传。可选的更新检查只读取 GitHub 上的公开版本信息。

下载前，先了解这些

你可能关心的几件事。

使用 ShotMap 需要注册账号吗？

不需要。下载应用后，就能在 Mac 上开始制作分镜图。

支持哪些 Mac？

ShotMap 支持运行 macOS 13 或更高版本的 Apple Silicon 与 Intel Mac。

我可以自己替换某一帧吗？

可以。智能选帧只是起点；手动选择画面让你决定最终画面。

分镜图保存在哪里？

默认保存在原视频旁边。你也可以用“另存为”选择其他位置。

现在就找找看？

下次找视频，先看分镜图。
