많은 동영상도 정리하기 쉽게

장면을 살펴보고 원하는 동영상을 찾으세요.

  1. 동영상 추가

    동영상을 하나만 드래그하거나 여러 개를 한 번에 추가하세요.

  2. 장면 확인

    자동 선택으로 시작한 뒤 원하는 프레임으로 바꾸거나 한 프레임씩 조정하세요.

  3. 이미지 저장

    원본 동영상과 같은 폴더에 PNG나 JPG로 저장하세요.

원하는 장면을 직접 선택

자동으로 고르고, 마지막은 직접 결정하세요.

타임라인과 프레임 이동 버튼으로 원하는 순간을 찾으세요. 자동 선택은 이미 고른 프레임을 유지하고 나머지 자리를 채웁니다.

  • 타임라인에서 후보 프레임 확인
  • 1프레임 또는 5프레임씩 앞뒤로 이동
  • 선택한 프레임을 동영상 시간순으로 표시

필요한 대로 꾸미세요

자주 쓰는 설정을 간편하게.

격자 크기

담고 싶은 장면 수에 맞춰 3 × 3부터 8 × 8까지 선택하세요.

파일 이름을 이미지에 표시

파일 이름과 타임코드를 표시하면 나중에 원하는 동영상을 빠르게 찾을 수 있습니다.

동영상에 맞는 화면

원본 동영상의 화면 비율을 사용하고 배경색을 선택하세요.

여러 동영상을 한 번에 정리

여러 동영상을 추가하고 준비된 프레임부터 확인하세요. 현재 동영상 처리가 끝나면 일시 정지할 수 있습니다.

동영상은 내 기기에만

동영상은 내 Mac에 그대로 남습니다.

프레임 추출과 이미지 저장은 Mac에서 처리합니다. 동영상은 업로드하지 않습니다. 선택 사항인 업데이트 확인은 GitHub의 공개 릴리스 정보만 읽습니다.

다운로드 전에

자주 묻는 질문

ShotMap을 쓰려면 계정이 필요한가요?

아니요. 앱을 다운로드하면 Mac에서 바로 스토리보드를 만들 수 있습니다.

어떤 Mac을 지원하나요?

macOS 13 이상을 지원합니다. 릴리스 페이지에서 Apple Silicon(M 시리즈)용 또는 Intel용 설치 파일을 선택하세요.

프레임을 직접 바꿀 수 있나요?

네. 스마트 선택으로 시작한 뒤 ‘프레임 직접 선택’에서 최종 장면을 고르면 됩니다.

스토리보드 이미지는 어디에 저장되나요?

기본적으로 원본 동영상과 같은 폴더에 저장됩니다. 저장 버튼으로 다른 위치를 선택할 수도 있습니다.

찾던 동영상이 있나요?

내 동영상을 더 편하게 살펴보세요.
