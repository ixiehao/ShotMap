# Product naming

Use the following names in all new user-facing copy, screenshots, installers,
and release notes. Keep the English name first when the three languages appear
together.

| Document language | Product name |
| --- | --- |
| English | `ShotMap` |
| 简体中文 | `视频一键拼图（ShotMap）` |
| 日本語 | `ShotMap（動画ワンクリック・モンタージュ）` |

## Compatibility identifiers

`ShotTessera` is a legacy technical identifier, not the product name. It is
intentionally retained in implementation identifiers where changing it would
break an existing installation or automation:

- Bundle identifier: `com.shottessera.videoscreenshotcollage`
- Swift package, module, executable, and Homebrew cask identifier:
  `shottessera`

The public repository and release URL remain `ixiehao/ShotTessera`; the product
name and distributed application are `ShotMap` and `ShotMap.app`.
